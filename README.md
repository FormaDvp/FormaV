### Старт

**Windows**

1. Скачайте **`FormaV_Win_v*.zip`** из [Releases](https://github.com/FormaDvp/FormaV/releases), распакуйте и запустите **FormaV.exe**.

**macOS**

1. Скачайте **`FormaV_Mac_v*.dmg`** из [Releases](https://github.com/FormaDvp/FormaV/releases), откройте и перетащите **FormaV** в «Программы».
2. Приложение не подписано Apple, поэтому macOS не откроет его с первого раза. Откройте **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение о FormaV и нажмите **«Всё равно открыть»**.
3. При первом запуске macOS запросит пароль для установки системного помощника (нужен для режима TUN).

**Дальше (везде)**

1. Добавьте подписку или ключ (**+** на главном экране).
2. Выберите сервер и нажмите кнопку подключения.

Настройки, маршрутизация и журнал и другое — в меню ⚙️ на главном экране.

---

Компоненты **Xray-core** и **wintun** распространяются на условиях своих авторов.
